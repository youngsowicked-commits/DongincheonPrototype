# Archived UE4 PhysX vehicle assets

The `Blueprints` and `Maps` directories in this archive came from
`Content/VehicleVarietyPack`.

Unreal Engine 5.8 no longer provides the `PhysXVehicles` and
`PhysXVehiclesEditor` classes used by these assets. Keeping the assets under
`Content` caused project-wide data validation failures. They are retained here,
outside Unreal's content scan, so they can be migrated to Chaos Vehicles later
without losing the original files.

The pack's meshes, skeletons, materials, and textures remain available under
`Content/VehicleVarietyPack`.
